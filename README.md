# Reels FR · Doc Juanes

Skill de Claude Code para editar los Reels de **Futuros Residentes / Doc Juanes**: corta tomas falsas y
silencios, limpia el audio, pone subtítulos con palabras resaltadas, cambia de plano en cada corte y
propone portadas. Funciona en **Mac** y en **Windows**.

Responsable del estilo y del skill: **Janeth Cardona**. Solo ella lo modifica; si encuentras una mejora
o un problema, escríbele.

## Instalar (una sola vez por computador)

1. Instala la app de escritorio de Claude y entra con la cuenta de la empresa.
2. **Solo en Windows:** instala Git for Windows (git-scm.com), que Claude Code necesita.
3. Abre la pestaña **Code**, empieza una conversación y pega este mensaje:

   > Instala el skill de edición de Reels: clona https://github.com/tatacardona/Reels-FR-Doc-Juanes.git en
   > la carpeta ~/.claude/skills/editar-reel-fr y prepara las herramientas del Paso 0 del skill. Explícame
   > cada paso antes de hacerlo.

4. Cuando termine, abre una conversación nueva. Listo.

## Usarlo

Abre una conversación **nueva por cada video** (ahorra tokens) y escribe, por ejemplo:

> Edita el guion 12 que está en Descargas.

Claude te presentará el plan con lo que hará y cuánto costará aproximadamente, y esperará tu aprobación.

## Actualizaciones

Cada vez que empieza un video, Claude trae la última versión del skill automáticamente.
